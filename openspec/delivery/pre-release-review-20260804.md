## 4. 非阻断边界与后续动作

1. **真实外部服务**：尚未在本机验证 WISE、IMA、企业 OAuth/JWKS、mTLS、Vault 和生产 PostgreSQL；上线前必须在目标环境执行独立联调。
2. **数据库只读防线**：应用层限制 SQL 形状，但生产 Connector 仍必须使用数据库只读账号、只读事务、语句超时和最小函数权限。
3. **来源链接治理**：前端只接受 HTTP/HTTPS 且使用 `noreferrer` 打开；企业部署建议再按 WISE/IMA 实际域名配置来源白名单。
4. **前端性能**：ECharts Canvas chunk 约 555 KB，已按业务场景异步加载，后续可继续按图表类型拆包。
5. **容器验证**：当前环境没有完成 Docker Compose 的真实拉起，GitHub Actions 也需在首次 push 后观察 Ubuntu Runner 结果。
6. **评测门禁**：48 场景综合通过 47/48（97.9%），`release-gate-v4` 仍未通过；不得对外表述为整体 100%。
